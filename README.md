# MiniEvent2024: Pothole Reporting Web Application

## Project Overview

MiniEvent2024 is a web-based application designed to allow users to report potholes in their area. This project aims to improve road safety and maintenance by providing an easy-to-use interface for citizens to report road issues. It is also intended as a teaching tool:
- **Base Version (`index.html`):** Demonstrates core web development concepts.
- **Enhanced Version (`optimized.html`):** Offers additional features (such as dynamic reporting, address autocomplete, reverse geocoding, and Firebase integration) that learners can implement if they have extra time.

## Features

- 🗺️ **Interactive Map:** View and navigate reported potholes on an interactive map powered by Leaflet.js.
- 📝 **Report Form:** Easily submit new pothole reports with your name and address.
- 📋 **List View:** Browse a list of current pothole reports.
- 📱 **Responsive Design:** Accessible on various device sizes, including mobile phones and tablets.
- 🔍 **Enhanced Functionality (Optional):** Learn how to add dynamic features such as real-time updates, autocomplete suggestions, and more.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Leaflet.js for map functionality
- Firebase (for the enhanced version)
- Nominatim API (for address autocomplete and reverse geocoding)

## Getting Started

### For **Users**

1. Open the application in your web browser (link to be provided).
2. Explore the map to see reported potholes.
3. Use the form to report a new pothole.

## How to Use

1. **View the Map:**
   - Use the interactive map to see reported potholes.
   - Click on a pothole marker to view details.
2. **Report a Pothole:**
   - Scroll to the form at the bottom of the page.
   - Enter your name and the address of the pothole.
   - Click "Submit" to add the report.
3. **Enhanced Version Features (Optional):**
   - The enhanced version includes live updates via Firebase, address autocomplete, and reverse geocoding for improved reporting accuracy.
